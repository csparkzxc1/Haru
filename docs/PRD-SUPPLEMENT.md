# PRD 보완 — 한국 시장 출시를 위한 리스크·규제·접근성

> 원본 PRD가 커버하지 않은 필수 고려사항. 출시 전 반드시 점검.

## 1. 개인정보보호법(PIPA) 대응

### 1.1 수집·이용 동의

- 필수/선택 동의 분리 화면 (필수만으로 가입 가능해야 함)
- **만 14세 미만 가입 금지** 또는 법정대리인 동의 절차
- 수집 항목·목적·보유기간을 한 줄 이내 평문으로 표기
- 마케팅 수신 동의는 기본값 **OFF**, 재확인은 2년마다

### 1.2 주요 의무

- **국내 저장**: 기본 저장소를 NCP 서울 리전 또는 AWS Seoul로 설정, 국외 이전 시 별도 고지
- **개인정보 처리방침**: `/privacy` 고정 링크, 최소 월 1회 검토
- **파기 기한**: 탈퇴 후 즉시 / 수사기관 요청은 개별 검토
- **정보주체 권리**: 열람·정정·삭제·처리정지 요청 채널을 앱 내 설정에 노출
- **DPO(개인정보보호책임자) 지정**: 연매출·이용자 수 초과 시 의무

### 1.3 가족 공유 기능 특수 사항

- 가족 구성원 중 미성년자 포함 시 법정대리인 동의
- 공유 Area의 데이터 소유권·삭제 권한 UX 설계 필수

## 2. 정보통신망법 / 위치정보법

- 위치 기반 리마인더(4.3)는 **위치정보사업자 신고** 대상 여부 검토
  - 개인위치정보를 수집·이용·제공 시 → 허가 또는 신고
  - 단말 내 처리만이면 면제 가능 → 법무 검토 필요
- 푸시/알림 → 광고성 정보 발송 시 **야간 시간(21:00-08:00) 별도 동의**
- 카카오 알림톡 사용 시 정보성/광고성 구분 철저

## 3. 전자상거래법 / 결제

- **구독 해지 절차**를 가입 절차와 동일 단계 수 이내로 제공 (다크패턴 금지)
- 자동결제 7일 전 사전 고지 (문자·이메일·앱 푸시 중 택)
- **청약철회**: 7일 이내 환불 가능 (디지털 콘텐츠 예외 고지)
- 토스/카카오페이/네이버페이 계약 시 각 PG사 약관 반영
- 세금계산서 발행 → 사업자등록증 기반 B2B 결제 플로우

## 4. 앱스토어 심사 대응

### 4.1 Apple App Store

- **Sign in with Apple 필수**: 타 소셜 로그인 제공 시 동등하게 제공해야 함
- **IAP 강제**: 디지털 구독은 Apple IAP 필수, 외부 결제 링크 금지 (한국 앱스토어는 예외 허용)
- 카카오 SDK 사용 시 IDFA 권한 프롬프트 처리
- 수동 심사 대비: 카카오/네이버 로그인 테스트 계정 제공

### 4.2 Google Play

- **Google Play Billing** 동일 원칙 (국내는 외부결제 혼용 가능)
- 위치권한 → 백그라운드 필요 시 별도 설명 영상 제출
- **데이터 보안 섹션** 정확 기재 (거짓 기재 시 제재)

### 4.3 One Store

- 국내 안드로이드 대체 마켓 대응 → 통신사 기본 탑재 유리
- 앱 패키지 분리 or 단일 AAB + 마켓 식별

## 5. 접근성 (Accessibility)

### 5.1 WCAG 2.1 AA 기준

- 색 대비 4.5:1 이상 (본문) / 3:1 이상 (대형 텍스트)
- 터치 타겟 44×44pt 이상
- 색에만 의존한 정보 전달 금지 (완료 = 색 + 체크 아이콘 + 취소선)

### 5.2 한국 표준

- **한국형 웹 콘텐츠 접근성 지침 (KWCAG 2.2)** 준수
- 공공기관 연동 예정이면 **장애인차별금지법** 대응 필수
- TalkBack·VoiceOver에서 한국어 레이블이 의미 단위로 읽히도록 `accessibilityLabel` 정비
- 다이내믹 타입(글자 크게) 시스템 설정 존중

### 5.3 고령 사용자 대응

- 시니어 모드: 폰트 +20%, 터치 타겟 +15%, 색 대비 ↑
- 음성 입력 버튼을 기본 노출 (자연어 파서와 연계)

## 6. 중요 보안·운영 항목

- **데이터 암호화**: 저장 시 AES-256, 전송 시 TLS 1.3
- **비밀번호 정책**: 영문+숫자+특수문자 8자 이상, 3개월 강제 변경 **폐지** (NIST/KISA 최신 권고)
- **2FA**: TOTP 또는 카카오 인증 연동
- **백업**: 일 1회 RDS 스냅샷 + 주 1회 오프사이트
- **감사 로그**: 개인정보 접근·변경 이력 최소 3년 보관
- **침해사고 대응**: KISA 신고 의무 24시간 이내 (중대 사고)

## 7. 로컬라이제이션 (L10n)

- 기본: **한국어**
- Phase 3 이후: 영어, 일본어 (재일동포·유학생 수요)
- 숫자·날짜·화폐 포맷: `Intl.DateTimeFormat('ko-KR')`, `Intl.NumberFormat('ko-KR', { style: 'currency', currency: 'KRW' })`
- 시간대: `Asia/Seoul` 고정 + 해외 거주자를 위한 `timezone` 프로필 옵션

## 8. 콘텐츠 정책

- 사용자가 입력한 할 일 텍스트에 대한 **암호화 저장** 원칙
- AI 어시스턴트가 Claude API로 보낼 때 **옵트인 필수**, 발신 전 개인정보 마스킹 (이름·전화·계좌)
- 학습 데이터 미사용 명시 (`anthropic-metadata` 옵션)
