# 예상 앱 화면 목업

`index.html`을 브라우저에서 열어 확인하세요.

```bash
# macOS
open docs/mockups/index.html
# Linux
xdg-open docs/mockups/index.html
# 또는 정적 서버
npx serve docs/mockups
```

## 포함 화면

| # | 화면 | 포커스 |
|---|------|--------|
| ① | 오늘 (모바일) | Quick Entry 자연어 파싱 실시간 미리보기 |
| ② | 이번주 (모바일) | 한국 직장인 전용 뷰 + 주간 히트맵 |
| ③ | 예정 (모바일) | 법정공휴일·대체공휴일·음력 기념일 |
| ④ | 프로젝트 + 공유 | 카카오톡 / 네이버 캘린더 공유 시트 |
| ⑤ | 오늘 · 다크모드 | 한글 가독성 위한 `#1C1C1E` |
| ⑥ | 웹 (데스크톱) | 사이드바 + 브레드크럼 + 이동시간 |

## 디자인 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--ink` | `#1C1C1E` | 본문 |
| `--paper` | `#FAFAF7` | 배경 (라이트) |
| `--accent` | `#FF6B35` | 강조 · 체크 · 버튼 |
| `--muted` | `#8E8E93` | 보조 텍스트 |
| 폰트 | Pretendard Variable | 본문 |
| 자간 | -0.01em | 한글 최적화 |
