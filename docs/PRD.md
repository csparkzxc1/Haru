# 하루 (Haru) — 한국형 To-Do 앱 PRD

> v0.1 · 2026-04-19 · 최초 작성

## 1. 역할 및 목표

Cultured Code의 Things 3가 가진 미니멀한 디자인과 계층 구조의 장점은 유지하되,
한국인의 업무·생활·학습 문화에 최적화된 To-Do 앱을 설계·개발한다.
Apple 전용이라는 한계를 넘어 **iOS/Android/Web 크로스플랫폼**을 기본으로 한다.

## 2. 벤치마크 분석 (Things 3의 계승 요소)

- **4단 뷰**: Today / Upcoming / Anytime / Someday
- **계층 구조**: Areas → Projects → Tasks → Checklists (+ Headings)
- **Magic Plus 버튼**, Quick Entry, 자연어 날짜 파싱
- **Markdown 노트**, 태그 시스템, 키보드 단축키
- **절제된 애니메이션**, 커스텀 타이포그래피
- **Shortcuts/자동화** 네이티브 지원

## 4. 한국 특화 차별화 기능 ⭐

### 4.1 로컬 연동

- **카카오톡 공유**: 할 일·프로젝트를 카톡 친구·오픈채팅·나에게 보내기
- **4-way 소셜 로그인**: 카카오 / 네이버 / Apple / Google
- **네이버 캘린더·구글 캘린더** 양방향 동기화
- **Toss·카카오페이 알림 연동**: 관리비·카드대금 결제일 자동 할 일 생성
- **카카오워크·잔디·네이버웍스** 기업용 메신저 연동 (B2B)

### 4.2 한국식 일정/날짜

- **음력 지원**: 음력 생일·제사·명절 반복 일정
- **24절기 & 법정공휴일** 자동 반영 (대체공휴일 포함)
- **"빨리빨리" 자연어 파싱**: "내일 점심때", "다음주 월요일 오전", "월말까지", "추석 전에", "월급날"
- **근무 일정 모드**: 주 52시간, 유연근무, 교대근무 템플릿

### 4.3 생활 컨텍스트

- **미세먼지·날씨 위젯 연동** → 야외 할 일 자동 재조정
- **대중교통 소요시간 자동 계산**: 지하철·버스 기반 이동시간 버퍼
- **동네 기반 장소 태그**: "올리브영 들르기", "GS25 택배 찾기" 위치 리마인더

### 4.4 한국 직장·학업 템플릿

- 주간보고·회의록·기안/품의서 체크리스트
- **대학 시간표 임포트** (에브리타임 CSV 호환)
- **인강 시청 추적** (메가스터디·이투스·패스트캠퍼스 북마크)
- **자격증 D-Day 위젯** (토익·정처기·공인중개사 등)

### 4.5 가족·관계 관리

- **가족 공유 Area**: 카카오톡 친구 선택으로 초대
- **경조사 관리**: 축의금·부의금 기록, 과거 이력으로 금액 추천
- **선물·답례 리스트**: 누구에게 뭘 받았는지 역추적

## 5. 정보 구조 (IA)

```
홈(오늘)
├─ 오늘 할 일 (Today)
├─ 이번주 (This Week)          ← Things에 없는 한국 직장인 선호 뷰
├─ 예정 (Upcoming)
├─ 언젠가 (Someday)
└─ 로그북 (Logbook)

영역(Areas)
├─ 회사
│   ├─ 프로젝트 A (마감일, 진행률, 담당자)
│   └─ 프로젝트 B
├─ 자기계발
├─ 가족 (공유)
└─ 개인

태그: #회의 #외근 #전화 #결재대기 #보고 #이메일 #15분컷 #집중필요
```

## 6. UX/UI 원칙

- **타이포그래피**: Pretendard 또는 Spoqa Han Sans Neo, 본문 15pt·자간 -1%
- **아이콘**: 자체 제작 모던·미니멀 셋 (과도한 민족주의 모티프 지양)
- **테마**: 라이트 / 다크 / 시스템. 다크모드는 순흑 대신 `#1C1C1E`
- **스와이프**: 왼쪽 → 미루기 (내일/다음주/언젠가), 오른쪽 → 완료
- **햅틱**: iOS 수준 촉각 피드백 → Android(OneUI/MIUI)에서도 구현
- **위젯**: 오늘 할 일 3개 / D-Day / 이번주 진행률 3종

## 7. 기술 스택

| 레이어 | 선택 | 근거 |
|--------|------|------|
| Frontend (Mobile) | React Native (Expo) + TypeScript, NativeWind | 크로스플랫폼 생산성 |
| Frontend (Web) | Next.js 14 App Router, Tailwind, Zustand | SSR·SEO·공유 용이 |
| Backend | NestJS + PostgreSQL + Prisma | 타입 안전·모듈화 |
| 캐시/큐 | Redis | 세션·푸시큐 |
| Storage | NCP Object Storage (S3 호환) | 국내 저장 마케팅 |
| 실시간 동기화 | Yjs (CRDT) + WatermelonDB | 오프라인 퍼스트 |
| 인프라 | NCP 또는 AWS Seoul | 데이터 국내 보관 |
| AI | Claude Opus 4.7 API | 회고·정리 자동화 |
| 푸시 | FCM + APNs + 카카오 알림톡 | 이중 발송 |
