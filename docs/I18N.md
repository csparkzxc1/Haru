# 국제화 (i18n) — ko / ja

Phase 4 의 "일본 확장(재일동포 수요)" 항목 구현. 외부 라이브러리 없이
경량으로 처리합니다 (`packages/shared/src/i18n.ts`).

## 지원 로케일

| 코드 | 표시 | 적용 범위 |
|---|---|---|
| `ko` | 한국어 | 기본. 모든 UI · 자연어 파서 · 공휴일 · 음력 |
| `ja` | 日本語 | UI 라벨 + 공휴일 + 표준 날짜 포맷. 자연어 파서는 한국어 전용. |

## 사용

```typescript
import { t, resolveLocale } from "@haru/shared/i18n";

// 정적
t("today", "ja");                 // "今日"
t("settings.colorMode.dark", "ja"); // "ダーク"

// 동적 (브라우저 / Expo Localization)
const locale = resolveLocale(navigator.language); // "ko-KR" → "ko"
t("today", locale);
```

## 일본 공휴일

`@haru/shared/japan-calendar` 는 한국 모듈과 동일한 인터페이스를 따른다:

```typescript
import { getHolidays as koHolidays } from "@haru/shared/korean-calendar";
import { getHolidays as jpHolidays } from "@haru/shared/japan-calendar";

const fn = locale === "ja" ? jpHolidays : koHolidays;
const holidays = fn(2026);
//   ko: [{name:"설날", date:..., substitute:false}, ...]
//   ja: [{name:"元日", date:..., substitute:false}, ...]
```

**구현 범위**
- 고정일 10종 (元日, 建国記念の日, 天皇誕生日, 昭和の日, 憲法記念日,
  みどりの日, こどもの日, 山の日, 文化の日, 勤労感謝の日)
- ハッピーマンデー 4종 (成人の日, 海の日, 敬老の日, スポーツの日) — 월요일 N번째 계산
- 春分の日 / 秋分の日 — NAOJ 표(2024~2030) 기반
- 振替休日 — 일요일 공휴일은 자동으로 다음 날로 보충

테스트: `packages/shared/src/japan-calendar.test.ts` (7 케이스).

## 적용 위치

| 영역 | 현재 | 다음 단계 |
|---|---|---|
| 백엔드 — `Accept-Language` 헤더 | 미적용 (모든 응답 ko) | 사용자 `User.locale` 컬럼 활용해 알림 / 이메일 본문 분기 |
| 웹 — 라우팅 | 단일 ko | Next.js i18n routing (`/ja/today`) — middleware 추가 후 활성화 |
| 웹 — UI 라벨 | 한국어 하드코딩 | `useTranslation()` 훅으로 `t(key)` 변환 |
| 모바일 — UI 라벨 | 한국어 하드코딩 | 동일한 `t(key)` |
| 자연어 파서 | 한국어 전용 | 일본어 파서 별도 추가 — 큰 작업이므로 실 사용자 demand 발생 후 |
| 앱스토어 메타데이터 | ko/ja 양쪽 (`docs/STORE.md`) | ✓ |
