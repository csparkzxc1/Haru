# 한국어 자연어 입력 명세

> 작성일: 2026-04-23  
> 목적: Haru의 핵심 차별화 — 한국어 자연어 할 일 입력 시스템  
> 상태: Phase 3~4 구현 대기 중

---

## 🎯 목표

**"Things 3의 한국어 버전"**을 달성하기 위한 자연어 파싱 엔진.

영어권 사용자가 Things 3에서 `"call mom tomorrow at 3pm"`처럼 쓰듯,  
한국 사용자가 `"내일 오후 3시에 엄마한테 전화"`처럼 자연스럽게 쓸 수 있어야 함.

---

## 💡 차별화 가치

```
Things 3:
  "tomorrow 3pm"     → 완벽 파싱
  "내일 오후 3시"     → 인식 안 함 ❌

Haru:
  "내일 오후 3시"     → 완벽 파싱 ✅
  "담주 월요일 !!"    → 완벽 파싱 ✅
  "3일 뒤 저녁"      → 완벽 파싱 ✅

→ 포지셔닝: "한국인이 만든 한국인을 위한 Things 3"
```

## 🔬 파싱 규칙 상세

### Rule 1: 요일 매핑

| 입력 | 결과 |
|---|---|
| `이번주`, `이주`, `금주` | 현재 주 |
| `담주`, `다음주`, `내주` | 다음 주 |
| `월`, `월요일` | monday |
| `화`, `화요일` | tuesday |
| `수`, `수요일`, `수욜` | wednesday |
| `목`, `목요일`, `목욜` | thursday |
| `금`, `금요일`, `금욜` | friday |
| `토`, `토요일` | saturday |
| `일`, `일요일` | sunday |
| `주말` | saturday or sunday |
| `평일` | mon-fri |

### Rule 2: 시간 매핑

| 입력 | 결과 (24h) |
|---|---|
| `새벽` | 05:00 |
| `아침` | 07:00 |
| `오전` | 09:00 (기본) |
| `점심` | 12:00 |
| `오후` | 14:00 (기본) |
| `저녁` | 19:00 |
| `밤` | 21:00 |
| `새벽` (깊은) | 02:00 |

**시간 파싱 규칙**:
- `X시` → X:00
- `X시 30분` / `X시 반` → X:30
- `X시 Y분` → X:Y

**AM/PM 명시 없을 때**:
- 1~8시: 애매 (문맥 추정)
- 9~12시: 오전 추정
- 1~6시: 오후 추정
- 7~11시: 밤 추정

**사용자 설정 고려**: "기본 추정 시간대" 선택 옵션

### Rule 3: 날짜 매핑

| 입력 | 결과 |
|---|---|
| `오늘` | today |
| `내일`, `낼` | tomorrow |
| `모레` | +2 days |
| `글피` | +3 days |
| `X일 뒤`, `X일 후` | +X days |
| `X주 뒤`, `X주 후` | +X weeks |
| `X개월 뒤`, `X달 뒤` | +X months |
| `M월 D일` | specific date |
| `M/D` | specific date |
| `M.D` | specific date |
| `월초` | 1일 |
| `월말` | last day of month |
| `연말` | 12/31 |
| `이번달` | current month |
| `다음달` | next month |

### Rule 4: 특수 키워드

| 입력 | 역할 |
|---|---|
| `까지` | deadline |
| `부터` | when (시작) |
| `동안` | duration |
| `!!`, `!!!` | priority: high |
| `★`, `⭐`, `중요`, `핵심` | star: true |
| `긴급`, `ASAP`, `급함` | priority: high |
| `?` | priority: low (드묾) |
| `15분컷`, `30분컷` | tag |
| `#XXX` | tag: XXX |

## 🎨 UX 디자인

### 실시간 피드백

사용자 타이핑 중, 파싱된 내용 **힌트로 미리 보기**:

```
입력 중: "내일"
  ↓
힌트 표시:
  📅 내일 (4월 24일 금요일)

입력 중: "내일 3시"
  ↓
힌트 표시:
  📅 내일 (4월 24일 금요일)
  🕐 오후 3:00

입력 중: "내일 3시 치과"
  ↓
힌트 표시:
  🏥 치과
  📅 내일 (4/24 금)
  🕐 오후 3:00
  [추가] 버튼
```

### 실패 시 Fallback

```
입력: "뭔가 이상한 말"
  ↓
파싱 실패 = 그냥 제목 그대로
  ↓
{ title: "뭔가 이상한 말" }
```

**실패해도 에러 X, 최소한 제목은 보존**.

### 모호한 경우

```
입력: "내일 모레 무엇"
  ↓
파싱: 모호 (내일 vs 모레)
  ↓
Alert: "내일인가요, 모레인가요?"
또는 첫 매칭(내일) 사용
```
